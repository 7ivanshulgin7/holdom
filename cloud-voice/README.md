# Джованни в Yandex Cloud Functions

Планшет записывает до восьми секунд звука и завершает запись после паузы. Функция открывает один сеанс Yandex AI Studio Realtime и возвращает ответ голосом Антона либо черновик дела вместе с доступной расшифровкой. Планшет передаёт последние восемь реплик для контекста. Календарная запись выполняется в holdom после подтверждения.

## Параметры функции

В каталоге Realtime создайте функцию `holdom-voice`. Загрузите `holdom-voice.zip` как ZIP-архив.

| Поле | Значение |
| --- | --- |
| Среда выполнения | `nodejs22` |
| Точка входа | `index.handler` |
| Память | `128 МБ` |
| Таймаут | `22 с` |
| Сервисный аккаунт | `holdom-realtime` с ролью `ai.models.user` |
| Переменная `YANDEX_FOLDER_ID` | `b1gsdhp5dmn0n3nu6948` |
| Переменная `HOLDOM_VOICE_CODE` | Случайный код из 64 строчных шестнадцатеричных символов |

Функция берёт IAM-токен сервисного аккаунта из `context.token.access_token`. Код планшета можно сгенерировать локально командой `node -p "require('node:crypto').randomBytes(32).toString('hex')"`.

После сохранения версии включите «Публичная функция». Проверьте запрос из holdom с правильным кодом. Функция принимает только POST с кодом планшета и разрешает чтение ответа браузером с GitHub Pages. Исходники и архив не содержат кода планшета, IAM-токена и ключа Яндекса.

## Подключение в holdom

В шестерёнке откройте «Облачный Джованни». Проверьте адрес и введите код планшета. Нажмите на часы, скажите фразу и сделайте паузу. Пример команды — «Запиши на завтра в шесть вечера купить цветы». Проверьте черновик перед сохранением.

В уже созданной функции для v21 создайте новую версию с обновлённым ZIP. Перенесите текущие переменные окружения и сервисный аккаунт. Ссылка функции и код подключения на планшете сохраняются.

Если версия возвращала `HTTP 502 · session_missing_credentials`, загрузите обновлённый архив в ту же функцию. Он исправляет передачу IAM-токена в Realtime.

Исправление `audio_timeout` использует серверное определение конца фразы (server VAD). Функция отправляет запись и заключительную паузу. Realtime начинает ответ сам.

Если Realtime обрывает ответ по лимиту, функция отдаёт полученную часть аудио и текста. Для других сбоев в holdom выводится статус Realtime и его причина, если сервис её передал.
