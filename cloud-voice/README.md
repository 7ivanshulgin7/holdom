# Джованни в Yandex Cloud Functions

Планшет записывает до восьми секунд звука. Функция открывает один сеанс Yandex AI Studio Realtime и возвращает ответ голосом Антона либо черновик дела. Календарная запись выполняется в holdom после подтверждения. Для каждой фразы создаётся новый сеанс.

## Параметры функции

В каталоге Realtime создайте функцию `holdom-voice`. Загрузите `holdom-voice.zip` как ZIP-архив.

| Поле | Значение |
| --- | --- |
| Среда выполнения | `nodejs22` |
| Точка входа | `index.handler` |
| Память | `128 МБ` |
| Таймаут | `22 с` |
| Сервисный аккаунт | `holdom-realtime` с ролью `ai.models.user` |
| Переменная `YANDEX_FOLDER_ID` | `b1gsdhp5dmn0n3nu6948` |
| Переменная `HOLDOM_VOICE_CODE` | Случайный код из 64 строчных шестнадцатеричных символов |

Сервисный аккаунт даёт функции IAM-токен. Ключ от локального теста вводить не нужно. Код планшета можно сгенерировать локально командой `node -p "require('node:crypto').randomBytes(32).toString('hex')"`.

После сохранения версии включите «Публичная функция». Проверьте запрос из holdom с правильным кодом. Функция принимает только POST с кодом планшета и разрешает чтение ответа браузером с GitHub Pages. Исходники и архив не содержат кода планшета, IAM-токена и ключа Яндекса.

## Подключение в holdom

В шестерёнке откройте «Облачный Джованни». Вставьте ссылку вызова из обзора функции и код планшета. Нажмите на смайлик и «Поговорить с Джованни». Скажите короткую фразу и нажмите «Отправить фразу». Пример команды — «Запиши на завтра в шесть вечера купить цветы». Проверьте черновик перед сохранением.
