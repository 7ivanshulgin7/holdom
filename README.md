# holdom

Семейное табло для старого Android-планшета у холодильника.

## Прототип

- Большие часы и дата, адаптивная раскладка для горизонтального планшета.
- Горизонтальное табло для Galaxy Note 10.1 (16:10). Слева верхнюю половину занимают часы и диалог Джованни, нижнюю — ближайшие дела. Справа календарь «Кто когда».
- Оформление в стиле iOS из «Кто когда». В шапке можно выбрать системную, светлую, тёмную тему, «Оливу» или «Шторм» из DM CRM.
- PWA-манифест и кэширование оболочки для повторного открытия без сети.
- Кнопка «На весь экран» в шапке переключает полноэкранный режим по нажатию. Для Chrome 55 используется вариант Fullscreen API с префиксом WebKit.
- Кнопка «Обновить» в шапке загружает свежую страницу. Без сети holdom открывает сохранённую копию.
- Кнопка «Не гасить экран» запоминает выбор. В старом браузере holdom запускает зацикленное видео без звука. Если браузер блокирует автозапуск, кнопка позволяет повторить запуск касанием. Удержание через видео зависит от браузера. Видео взято из NoSleep.js, лицензия в `keep-awake-LICENSE.txt`.

Для календаря используйте ключ входа из «Кто когда». На семейном планшете выбран вариант с аккаунтом Леры. События берутся из `GET /state`. Ближайшее дело видно под часами, рядом с месяцем и делами выбранного дня. Ключ сохраняется в браузере планшета после успешного входа.

Нажмите на часы и задайте вопрос. Holdom отправляет фразу после паузы. Расшифровка и ответ появляются под часами, последние реплики передаются Джованни для уточняющих вопросов. Голосовой запрос требует доступа к микрофону.

Если продиктовали новое дело, откройте его кнопкой «Проверить дело» или командой «Покажи черновик». Проверьте название, дату и время. Затем нажмите «Сохранить дело» или произнесите эту команду через кнопку «Сказать команду» в открытом черновике.

Под часами можно открыть форму дела или сделать заметку. Заметки сохраняются только на планшете. При подключённом голосе эти действия можно вызвать фразами «Записать дело» и «Сделай заметку».

Шестерёнка в шапке открывает оформление, настройки голоса, вход в календарь и поиск людей.

Месяцы прокручиваются одной вертикальной лентой. Календарь открывается на текущем месяце. В настройках можно вернуться к сегодняшней дате и включить прошлые месяцы. Фильтр по людям действует на ленту, дела выбранного дня и три ближайших дела.

На горизонтальном планшете табло занимает один экран. Сетка показывает месяц целиком. Соседние даты в первой и последней неделе приглушены. Нажатие на день открывает список дел поверх табло.

Месяц использует цвета и узоры профилей из «Кто когда». Общее дело занимает один цветной блок с полосами участников. Соседние дни одного многодневного дела соединяются, прошедшие даты приглушаются, сегодня отмечено красным, выбранный день обведён.

Для установки опубликуйте сайт по HTTPS вместе с `icon-192.png` и `icon-512.png`. Откройте сайт в Chrome и выберите «Установить» или «Добавить на главный экран». На Android 5.1.1 результат зависит от браузера. Если добавится обычный ярлык, он будет открывать табло в браузере.

## Следующие шаги

1. Проверить размеры, шрифты и читаемость на Galaxy Note 10.1 2014 в альбомной ориентации.
2. Согласовать поля и права отдельного пользователя «Дом» в «Кто когда»; подключить семейные дела и ответы на приглашения.
3. Определить домашний backend и безопасную авторизацию для общего списка покупок.
4. Подключить Джо к добавлению/чтению покупок и отправке списка в Telegram.
5. Добавить киоск-режим/удержание экрана и отдельную страницу конфигурации.

## Разработка

При выпуске меняйте номер и дату в `APP_VER` в `app.js`, номер кэша в `sw.js` и параметры `?v=` у CSS и JS в `index.html` и `sw.js`. Номер и дата показаны рядом с названием holdom.

Это ванильные HTML/CSS/JS без сборщика. Service Worker работает только с localhost или HTTPS.

Голос Джованни запускается по запросу в Yandex Cloud Functions. Расшифровка, контекст и голосовые команды в v21 требуют обновлённого архива функции. Инструкция находится в [cloud-voice/README.md](cloud-voice/README.md).
