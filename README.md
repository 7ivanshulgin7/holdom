# holdom

Семейное табло для старого Android-планшета у холодильника.

## Прототип

- Большие часы и дата, адаптивная раскладка для горизонтального планшета.
- Горизонтальное табло для Galaxy Note 10.1 (16:10). Часы и домашнее дело слева, календарь «Кто когда» справа, карточка Джо внизу слева.
- PWA-манифест и кэширование оболочки для повторного открытия без сети.
- Кнопка «На весь экран» в шапке переключает полноэкранный режим по нажатию. Для Chrome 55 используется вариант Fullscreen API с префиксом WebKit.
- Кнопка «Не гасить экран» в шапке. На HTTPS с Screen Wake Lock выбор сохраняется. В старом браузере кнопка запускает видео без звука, её нужно нажимать после каждого открытия. Удержание в этом режиме зависит от браузера. Видео взято из NoSleep.js, лицензия в `keep-awake-LICENSE.txt`.

Для календаря используйте ключ входа из «Кто когда». На семейном планшете выбран вариант с аккаунтом Леры. События берутся из `GET /state`. Справа сверху видно ближайшее дело, под ним месяц с цветами участников и список дел выбранного дня. Ключ сохраняется в браузере планшета после успешного входа. Карточка домашних дел пока демонстрационная.

В карточке Джо нажмите «Добавить дело», затем «Диктовать» или запишите название вручную. Проверьте дату и время и нажмите «Сохранить». Дело добавляется в подключённый календарь и видно его связям, как при обычном добавлении в «Кто когда». Диктовка использует распознавание речи браузера и требует доступа к микрофону. Пример: «Завтра в 18:30 забрать посылку».

Кнопка «Открыть „Кто когда“» переходит в полный календарь. На GitHub Pages приложения используют один origin, поэтому при свободном сеансе «Кто когда» может принять вход из holdom через хранилище браузера. При другом ключе или незавершённых изменениях переход предложит сначала завершить прежний сеанс.

После входа кнопка «Люди» позволяет найти человека по имени или нику и отправить ему запрос. Встречный запрос можно принять из тех же результатов поиска.

Для установки опубликуйте сайт по HTTPS вместе с `icon-192.png` и `icon-512.png`. Откройте сайт в Chrome и выберите «Установить» или «Добавить на главный экран». На Android 5.1.1 результат зависит от браузера. Если добавится обычный ярлык, он будет открывать табло в браузере.

## Следующие шаги

1. Проверить размеры, шрифты и читаемость на Galaxy Note 10.1 2014 в альбомной ориентации.
2. Согласовать поля и права отдельного пользователя «Дом» в «Кто когда»; подключить семейные дела и ответы на приглашения.
3. Определить домашний backend и безопасную авторизацию для общего списка покупок.
4. Подключить Джо к добавлению/чтению покупок и отправке списка в Telegram.
5. Добавить киоск-режим/удержание экрана и отдельную страницу конфигурации.

## Разработка

При выпуске меняйте номер и дату в `APP_VER` в `app.js`, номер кэша в `sw.js` и параметры `?v=` у CSS и JS в `index.html` и `sw.js`. Номер и дата показаны рядом с названием holdom.

Это ванильные HTML/CSS/JS без сборщика. Service Worker работает только с localhost или HTTPS.
